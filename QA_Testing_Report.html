6 Pre-Release Bug Resolution & Hardening Log

BUG-01: Bulk CSV Import Mongoose Enum Crash on Automatic Category Creation Critical Severity
Problem & Root Cause: When a bulk CSV row contained a brand new category, the server created it on the fly without setting a valid department enum. The Mongoose schema strictly requires department from five allowed values (grocery-kitchen, snacks-drinks, etc.), triggering an unhandled ValidationError that crashed the import batch.
Engineering Fix: Implemented resolveDepartment(rawDepartment, categoryName) in importController.js that extracts keywords (e.g. snack, beverage, cosmetic, hygiene) or defaults safely to grocery-kitchen.
✓ Automated Verification: TC-10 verified with brand new category; import completed with 2 succeeded and 0 schema validation crashes.
BUG-02: Mobile Touchscreen Vertical Scroll Lock on Admin Tables Major Severity
Problem & Root Cause: Admin tables wrapped in .admin-table-scroll were styled with touch-action: pan-x;. On mobile touchscreens, this locked vertical swipe gestures, preventing users from scrolling down the page when their finger touched any table row.
Engineering Fix: Updated admin.css rule to touch-action: pan-x pan-y; and isolated table horizontal scroll with -webkit-overflow-scrolling: touch; while parent .admin-card maintains overflow: visible;.
✓ Automated Verification: TC-21 audited computed styles across all 3 admin tables on 375x812; programmatic vertical scroll confirmed smooth access to the bottom rows.
BUG-03: Add/Edit Product Modal Viewport Clipping on Mobile Screens Major Severity
Problem & Root Cause: Unconstrained modal heights on small screens (iPhone 375×812) caused the modal card to stretch beyond the visible viewport fold, pushing the Save and Cancel action buttons off-screen and blocking product creation on mobile.
Engineering Fix: Implemented a responsive bottom-sheet modal pattern for viewports < 768px: constrained modal with max-height: 92dvh;, scrollable internal .form-grid (overflow-y: auto;), and docked sticky .modal-actions.
✓ Automated Verification: TC-22 verified modal height constrained to 747px (within 92dvh of 812px viewport); Save and Cancel buttons remained fully visible and clickable.
